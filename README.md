

# 🥔 Potato Leaf Disease Detection

A deep learning-based web application that detects potato leaf diseases using a Convolutional Neural Network (CNN). The application allows users to upload a potato leaf image and predicts whether the leaf is **Healthy**, affected by **Early Blight**, or affected by **Late Blight**.

👉 [🥔 Potato Leaf AI Scanner]
(https://potato-disease-detector.streamlit.app/)

> If your actual Streamlit URL is different, replace the URL above with your deployed application URL.

---

## 📌 Project Overview

Potato crops can be affected by diseases such as Early Blight and Late Blight, which can negatively impact crop health and production.

This project uses **Deep Learning and Computer Vision** to automatically classify potato leaf images into three categories:

* 🌿 Healthy
* 🍂 Early Blight
* ⚠️ Late Blight

The trained TensorFlow/Keras model is integrated into a **Streamlit web application** where users can upload an image and receive an AI-based prediction with a confidence score.

## 🧠 Machine Learning

The project uses a **Convolutional Neural Network (CNN)** for image classification.

### Classification Classes

| Class           | Description                                             |
| --------------- | ------------------------------------------------------- |
| 🌿 Healthy      | Potato leaf appears healthy                             |
| 🍂 Early Blight | Leaf shows characteristics associated with Early Blight |
| ⚠️ Late Blight  | Leaf shows characteristics associated with Late Blight  |

### Model

* Framework: TensorFlow
* Deep Learning API: Keras
* Model Type: Convolutional Neural Network
* Input Image Size: 256 × 256
* Output Classes: 3
* Model Format: `.keras`

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Abdullah-07-lko/Potato-Disease-Detection.git
```

Navigate to the project:

```bash
cd Potato-Disease-Detection
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the environment on Windows:

```bash
venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser.
